# 视频分段剪辑工具 · 使用说明

当前版本 v1.6

## 功能

把一段视频按固定秒数均匀拆分成多个 MP4 片段并全部导出。例如：30 秒视频按每段 5 秒拆分 → 导出 6 个视频。

还可设置：导出画面比例（1:1 / 3:4 / 9:16 / 16:9 / 自定义）、从第几秒开始切分；拆分过程中可随时暂停/继续。

## 包含文件

1. `视频分段剪辑工具_v1.6.exe` —— 图形界面版（推荐，双击即用）
2. `分段剪辑_命令行版_v1.6.exe` —— 命令行版（可选，供批量/进阶使用）

> 在 GitHub Releases 单独下载时，文件名对应为 `VideoSegmentSplitter_v1.6.exe`（图形界面版）与 `VideoSegmentSplitter_v1.6_CLI.exe`（命令行版）；下载 `_full.zip` 解压后则为上述中文名。

## 图形界面版使用方法

1. 双击「视频分段剪辑工具_v1.6.exe」（无需安装任何软件）
2. 点击「添加视频」，可一次选择多个视频
3. 设置参数：
   - **起始时间（秒）**：从视频的第几秒开始切分，0 表示从头开始
   - **每段时长（秒）**：默认 5 秒
   - **导出画面比例**：1:1 / 3:4 / 9:16 / 16:9 / 原始 / 自定义
     - 选预设比例输出标准尺寸（如 9:16 → 1080×1920）
     - 画面处理二选一（默认「保持完整画面」）：
       - 保持完整画面：原画面内容完整保留，等比缩放后不足处补黑边
       - 裁剪填满：画面居中裁剪到目标比例，超出部分会被裁掉
     - 选「自定义」后直接输入目标分辨率（如 1080x1920），或输入宽:高比例（如 4:5）
     - 设置了比例时自动使用精确切分（流复制无法改比例）
   - **音频**：可选「视频原声」（默认）或「自定义音频」
     - 选「自定义音频」后点击「选择音频…」，选择 mp3/wav/m4a 等音频文件
     - 自定义音频会替换视频原声，且被视为整条连续配乐——各切片按其在原视频中的时间点衔接取音（切片之间音乐连续播放，不会每段都从头开始）；音频比视频短时自动循环补齐，比视频长时自动截断
   - **暂停/继续**：拆分过程中点主按钮可随时暂停，再点继续
4. 选择切分方式（未设置比例时可用）：
   - **精确切分（默认）**：切点精确到指定秒数，视频会重新编码，画质与原片基本无差异
   - **快速切分**：不重新编码、速度极快、画质零损失，但切点会对齐到最近的关键帧，每段时长可能有 ±0.5 秒左右偏差
5. 选择输出目录（默认为视频所在目录下的 `output_分段` 文件夹）
6. 点击「开始拆分并导出」，完成后可在输出目录查看全部片段

## 命令行版使用方法

打开 cmd，执行：

```bat
分段剪辑_命令行版_v1.6.exe --cli "视频路径.mp4" 每段秒数 "输出目录"
```

示例：

```bat
分段剪辑_命令行版_v1.6.exe --cli "C:\video\a.mp4" 5 "C:\video\output"
```

不填输出目录时，默认输出到视频所在目录的 `output_分段` 文件夹。

## 常见问题

**Q：双击后 Windows 提示「已保护你的电脑」？**
A：点击「更多信息」→「仍要运行」。本工具为独立打包程序，不含联网行为。

**Q：输出的视频能在手机/微信上播放吗？**
A：可以。输出为标准 MP4（HEVC/H.265 + AAC），与原片编码一致；如需兼容性更广的 H.264 版本，可联系制作者调整。

**Q：末尾不足一段的视频会被丢弃吗？**
A：不会。剩余不足一整段的内容会作为最后一段完整导出。

**Q：支持哪些输入格式？**
A：mp4 / mov / mkv / avi / flv / webm / m4v / ts 等常见格式。
