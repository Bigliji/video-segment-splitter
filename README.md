# 视频分段剪辑工具
详细介绍
把一段视频按固定秒数**均匀拆分成多个 MP4 片段**并批量导出。Windows 单文件程序，免安装、免依赖，双击即用。

**当前版本 v1.6** · 平台 **Windows 10 / 11 64 位**

## 核心功能

- **均匀切分**：按指定秒数等分视频。例：30 秒视频、每段 5 秒 → 导出 6 个片段
- **画面比例**：1:1、3:4、9:16、16:9、原始，或自定义分辨率/比例
- **两种画面策略**：等比缩放补黑边（保持完整画面）／居中裁切（填满画面）
- **自定义配乐**：替换原声，按原视频时间轴连续衔接，切片之间音乐不中断
- **两种切分方式**：精确切分（重编码）／快速切分（流复制）
- **断点控制**：可设起始时间，拆分过程可暂停、继续

## 快速上手

1. 双击 `视频分段剪辑工具_v1.6.exe`
2. 点击「添加视频」，支持一次选择多个文件
3. 设置每段时长、导出画面比例、音频
4. 选择切分方式：精确切分／快速切分
5. 选择输出目录（默认输出到视频所在目录下的 `output_分段` 文件夹）
6. 点击「开始拆分并导出」

## 命令行版

```bat
分段剪辑_命令行版_v1.6.exe --cli "视频路径.mp4" 每段秒数 "输出目录"
```

省略输出目录时，默认写入视频所在目录的 `output_分段` 文件夹。

## 常见问题

**末尾不足一整段的部分会被丢弃吗？** 不会，剩余内容会作为最后一段完整导出。

**支持哪些输入格式？** mp4 / mov / mkv / avi / flv / webm / m4v / ts 等常见格式。

**输出的视频能在手机或微信上播放吗？** 可以，输出为标准 MP4（HEVC/H.265 + AAC）。
