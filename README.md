# 视频分段剪辑工具

把一段视频按固定秒数**均匀拆分成多个 MP4 片段**并批量导出。Windows 单文件程序，免安装、免依赖，双击即用。

当前版本 **v1.6** · 平台 **Windows 10 / 11 64 位**

## 核心功能

- **均匀切分**：按指定秒数等分视频。例：30 秒视频、每段 5 秒 → 导出 6 个片段。
- **画面比例**：1:1、3:4、9:16、16:9、原始，或自定义分辨率/比例。
- **两种画面策略**：保持完整画面（等比缩放补黑边）／裁剪填满（居中裁切）。
- **自定义配乐**：替换原声，按原视频时间轴连续衔接，切片之间音乐不中断。
- **两种切分方式**：精确切分（重编码）／快速切分（流复制）。
- **断点控制**：可设起始时间，拆分过程可暂停、继续。

## 图形界面版使用步骤

1. 双击 `视频分段剪辑工具_v1.6.exe`
2. 点击「添加视频」，支持一次选择多个文件
3. 设置参数（见下表）
4. 选择切分方式：精确切分／快速切分
5. 选择输出目录（默认输出到视频所在目录下的 `output_分段` 文件夹）
6. 点击「开始拆分并导出」

### 参数说明

| 参数 | 默认值 | 说明 |
|---|---|---|
| 起始时间 | 0 秒 | 从视频第几秒开始切分 |
| 每段时长 | 5 秒 | 单个片段的长度 |
| 导出画面比例 | 原始 | 预设比例输出标准尺寸（如 9:16 → 1080×1920）；选「自定义」可直接输入 `1080x1920` 或 `4:5` |
| 画面处理 | 保持完整画面 | 保持完整画面＝等比缩放补黑边；裁剪填满＝居中裁切，超出部分丢弃 |
| 音频 | 视频原声 | 选「自定义音频」后可指定 mp3 / wav / m4a 等文件 |
| 切分方式 | 精确切分 | 见下方对比 |

### 两种切分方式对比

| | 精确切分 | 快速切分 |
|---|---|---|
| 是否重编码 | 是 | 否（流复制） |
| 切点精度 | 精确到指定秒数 | 对齐到最近关键帧，偏差约 ±0.5 秒 |
| 速度 | 较慢 | 极快 |
| 画质 | 与原片基本无差异 | 零损失 |
| 能否改比例 | 支持 | 不支持 |

设置了导出比例时会自动切换到精确切分，因为流复制无法改变画面比例。

### 自定义音频的行为

自定义音频被视为**整条连续配乐**，各切片按其在原视频中的时间点取音：切片之间音乐连续播放，不会每段都从头开始。音频短于视频时自动循环补齐，长于视频时自动截断。

## 命令行版

```bat
分段剪辑_命令行版_v1.6.exe --cli "视频路径.mp4" 每段秒数 "输出目录"
```

示例：

```bat
分段剪辑_命令行版_v1.6.exe --cli "C:\video\a.mp4" 5 "C:\video\output"
```

省略输出目录时，默认写入视频所在目录的 `output_分段` 文件夹。

## 常见问题

**双击后提示「已保护你的电脑」？**
点击「更多信息」→「仍要运行」。程序未签名，属正常现象。

**输出的视频能在手机或微信上播放吗？**
可以。输出为标准 MP4（HEVC/H.265 + AAC），编码与原片保持一致。若需要兼容性更广的 H.264 版本，需要另行处理。

**末尾不足一整段的部分会被丢弃吗？**
不会。剩余内容会作为最后一段完整导出。

**支持哪些输入格式？**
mp4 / mov / mkv / avi / flv / webm / m4v / ts 等常见格式。

**运行环境要求？**
Windows 10 / 11 64 位。无需安装 Python 或任何依赖。
